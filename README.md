# Footstep-Based-Piezoelectric-Power-Generation

PIEZOELECTRIC BASED ELECTRICITY GENERATION SYSTEM
Using Arduino Uno

--------------------------------------------
PROJECT OVERVIEW
--------------------------------------------
This project demonstrates electricity generation using piezoelectric sensors.
Mechanical pressure such as footsteps or vibrations is converted into electrical energy,
stored in a battery, and monitored using Arduino Uno.

The system displays real-time generated voltage and charging status on a 16x2 LCD.

--------------------------------------------
FEATURES
--------------------------------------------
- Converts mechanical energy into electrical power
- Uses piezoelectric sensor array
- Battery charging and monitoring system
- Real-time voltage display on LCD
- LED charging indicator
- Low cost and eco-friendly solution

--------------------------------------------
HARDWARE COMPONENTS
--------------------------------------------
- Arduino Uno
- Piezoelectric sensors (multiple)
- Bridge rectifier
- Voltage divider circuit
- Boost converter
- Rechargeable battery
- 16x2 LCD display
- LED indicator
- Capacitors and resistors

--------------------------------------------
SOFTWARE USED
--------------------------------------------
- Arduino IDE
- Embedded C (Arduino language)

--------------------------------------------
WORKING PRINCIPLE
--------------------------------------------
Pressure applied on piezoelectric sensors generates AC voltage.
The rectifier converts AC to DC.
The DC voltage is regulated using a boost converter.
Energy is stored in the battery.
Arduino monitors voltage and displays it on LCD.

--------------------------------------------
PIN CONFIGURATION
--------------------------------------------
A0  -> Voltage sensor input
2-7 -> LCD pins
8   -> LED indicator

--------------------------------------------
OUTPUT
--------------------------------------------
- Displays generated voltage
- Shows battery charging status
- Lights LED when battery reaches threshold
